# Gate 3 seven-kind checkpoint — Standards review

Pinned range: `bb24210c01e0dc1bcbc2d4fdf197d07a7a17035d...398e5f186007e603fe878afc7ce7bbe9eddf3640`

1. **[P1, documented behavior/security breach] Link admission can commit credentials or a non-checkoutable value.** `workspace-linked-routes.ts:170-198` computes a canonical URL (which removes URL userinfo) for checks, but sends the original `body.gitUrl`; `link-declarations.ts:17-38` then uses normalization only for matching and serializes that original value into `repositories/*.md`. Thus `https://token@github.com/acme/repo.git` writes `token` to the default branch, while any nonempty garbage string can produce a declaration that hydrate accepts syntactically. This violates `02-hydration-contract.md:45` (“No secrets in git”), `03-knowledge-file-layout.md:43` (the value must be a checkoutable URL), and ADR-033’s preservation of locked product behavior. Validate a domain Git-remote type and persist/emit its credential-free canonical value before enqueue.

2. **[P2, correctness defect] The node-preserving YAML path still fails valid aliases.** `hydrate-write-jobs.ts:126-135,165-167` treats a top-level `claims: *claim_list` alias as a non-sequence even when it resolves to a sequence. Lines 188-193 delete `import_key` without preserving aliases that reference its anchor; `knowledge-metadata.ts:17` then throws `Unresolved alias`. These valid documents fail the claims/validity/cleanup job rather than preserving unrelated metadata. Resolve aliases for sequence mutation and materialize or relocate referenced anchors before deletion; add native cases for both shapes.

3. **[Non-blocking Fowler heuristic: Primitive Obsession/Data Clumps/Shotgun Surgery]** `write-job-intent.ts:17-29,61-71` and `write-command.ts:21-31` model every command as an optional-property bag. Illegal states compile and parse (for example, link without URL, or bootstrap with link fields), and each new datum must be threaded through schema, durable payload, claim comparison, and resume reconstruction. A discriminated union keyed by `kind` would centralize each immutable command shape. Native admission’s kind-specific schemas currently contain the runtime impact, so this is refactoring guidance.

**Result:** two blocking correctness findings (one documented P1, one P2) and one non-blocking smell. The prior rename, Layer-1, and encoded-folder-path findings are fixed in the pinned blobs.
