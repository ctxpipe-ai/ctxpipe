# Sources

Craft, not volume. Public “generate 6–30 logos” skills repeat the failure this repo already had.

## Adopt

| Source | What we took |
| --- | --- |
| Ian Paget / Logo Geek — [fundamentals](https://logogeek.uk/logo-design/ultimate-guide), [optical corrections](https://logogeek.uk/logo-design/optical-corrections/) | Identify, don’t explain. Correct by eye (overshoot, optical center, irradiation). |
| Tobias Frere-Jones, *Typeface Mechanics* | Curves and points overshoot flats. |
| Sagi Haviv | A logo is the period, not the sentence. |
| RampStack [logo-design](https://rampstack.co/skills/logo-design) (MIT, reference only) | Mark **architecture** (wordmark / lockup / letterform-as-symbol). Design the **smallest** surface first (here: 20px sidenav, 16px mark). Restraint tests: silhouette, one-color, two-second. Fallback hierarchy from one geometry. |
| This repo, 2026-08-15 | A metaphor-only Sol loop greens broken letters. Integrity is a scorecard + calibration fixture. |

## Leave on the table

- Volume generators (N concepts × M SVGs, “pick a winner,” no type control).
- RampStack’s **6–12 variants for a client deck** as the default loop — too many near-duplicates; we cap at **three** directions, then integrity.
- AI-image “logo with the word ctx” prompts (garbled type). Wordmarks are set in a real face or drawn as type, never sampled from a picture model.
