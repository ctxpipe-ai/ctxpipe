# CTX-585: stable CI jobs

Ticket: https://linear.app/ctxpipe/issue/CTX-585

Source: every failed job in the CI runs of the PR 280 branch from 2026-10-11 to 2026-10-12, all attempts. Jobs with a code cause are not in this table. Examples are the Typecheck errors in the email templates, the `email-verification` tests, the `repository-ingestion-owner-native` backfill on three heads, and the Confluence admission cases that a later commit removed. The aggregate `Tests` job fails when a lane fails or a run is canceled. It has no cause of its own.

## Follow-ups

- The base fallback cause is still open. When the base contract fails, read the warnings in its message.
- The codesearch image has no layer cache in CI. A cache (buildx with `type=gha`) would stop most downloads, but the image is large. This could fill the 10 GB repository cache.
