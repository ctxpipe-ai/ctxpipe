# Project workspace IA and interaction contract

Type: grilling
Status: open
Blocked by: 15

## Question

After reacting to [Project workspace UI prototype](15-project-workspace-ui-prototype.md), lock the information architecture and interaction contract for the production UI.

Settle:

- Nav: Projects list vs Home, Repositories, Connectors. What remains top-level?
- Click vs chevron on a Project row (open chat vs last-5 conversations).
- New conversation: when it is named, where it appears, what happens to the previous session.
- Right-panel tabs: files / graph / settings — defaults, URL deep-linking, whether the panel is closable.
- File browser: single-click preview vs double-click tab; tree collapse rule.
- Settings: the create/select/relink flows from [Project repository create, select, relink, and import](09-project-repository-lifecycle.md) — which of those are in this panel vs elsewhere.
- Worktree name placement.
- Connector settings: org-level Connectors page vs per-project settings.
- Graph tab: the current org-wide graph, or project-scoped hydrate of that Project only?

This is the decision. The prototype is evidence. Do not reopen visual polish here.
