# T08 Run-scoped ingest refs

## What

- `apps/backend/src/domain/ingestion/ingest-refs.ts`: the ref job core.
  - Names: `refs/ctxpipe/ingest/<runId>/<workspaceId>/shards/<shard>` and `refs/ctxpipe/ingest/<runId>/<workspaceId>/assembled`. Each segment matches `[A-Za-z0-9][A-Za-z0-9_-]{0,127}`.
  - `pushIngestStep`: refuses a ref that is not of the job's run and Workspace. Reads the remote tip with `ls-remote`. Fetches the base (the old tip, or the pinned revision for the first commit). Runs the T06 validator against the base. Commits the accepted tree with parent = base, a fixed author and committer time (the run's `authorTime`), and the `Ctxpipe-Run`, `Ctxpipe-Step`, and `Ctxpipe-Bundle` trailers. Pushes with `--force-with-lease=<ref>:<oldTip or empty>`. The parent is the old tip, so each push is a fast-forward. When the remote is already at the computed SHA (a replay after a push), it pushes nothing and returns the SHA. A lease refusal becomes `IngestRefRefusedError`.
  - `findStepCommit`: the resume helper. It returns the tip when the trailers of the tip name this run and step, else null.
  - `deleteRunIngestRefs`: deletes the refs of one run in one Workspace. Idempotent (for T21 `delete-refs`).
  - `cleanUpIngestRefs`: lists `refs/ctxpipe/ingest/*`, reads the tip commit times (a `--depth=1 --filter=tree:0` fetch), and deletes, with a lease on the listed tip: the refs of runs that are not unfinished, and refs older than 24 hours. In shadow mode it keeps refs for 7 days and does not read the run status. A name that does not parse goes after 24 hours.
- `domain/workspaces/write-broker.ts`: `pushWorkspaceIngestStep`, `deleteWorkspaceIngestRefs`, and `cleanUpWorkspaceIngestRefs`. They get the remote URL and the GitHub App write token from the job's Workspace. The job never names a URL, so it cannot reach another repository. The run status comes from `unfinishedOrgWorkflowRunIds` (`repository-ingestion-v2`).
- `openworkflow/workflows/workspace-tip-check.ts`: runs the clean-up for each writable, GitHub-connected Workspace with access. A failure logs `workspace_ingest_ref_cleanup_failed` and does not fail the tip check.
- `domain/ingestion/ingestion-run.ts`: `INGESTION_V2_SHADOW = true` (committed config; the switch tickets set it to false).
- `routes/webhooks/github/github.ts`: a push to `refs/ctxpipe/` returns early (spike follow-up). It starts no tip check, ingestion, or connector sync.

## Why

Concept section 7, ADR-052 section 6. The ref names differ from the concept: git cannot hold `…/<workspaceId>` next to `…/<workspaceId>/<shard>` (a directory/file conflict; checked with a bare remote). ADR-052 and the concept now use `shards/<shard>` and `assembled`.

## Tests

- `ingest-refs.test.ts` (14 tests, real git, bare remotes): names and unsafe names; the first commit on the pinned revision, trailers, fixed times, the default branch does not change, a default clone does not fetch the ref; the validator runs against the base and drops a rejected path; advance from the old tip; a replay makes the same SHA (also on a second remote) and a second push is a no-op; a wrong old tip is refused in three forms and the ref does not move; two racing pushes: one wins, one is refused; refs outside the run's names are refused and no remote ref changes; the resume helper finds the commit after a crash after the push and returns null for another step, another run, and a missing ref; delete of one run's refs is idempotent and keeps another run's ref; clean-up deletes a finished run's ref and a 25-hour-old ref, keeps a running run's ref and `main`; shadow refs stay until 7 days; no refs means no run-status query.
- `github.test.ts`: a push to an ingest ref enqueues no tip check and no ingestion (red before the change).
- `workspace-tip-check.contract.test.ts`, the T06/T07 ingestion tests, and the webhook tests pass (14 files, 108 tests) on the per-worktree database. `pnpm typecheck` exit 0. Test policy exit 0.

## Risks

- The broker wrappers in `write-broker.ts` have no test with a GitHub remote; the core has the tests. T09's Docker contract covers them end to end.
- The tip check mints a write token for each writable Workspace on each check (octokit caches installation tokens).
- `--depth=1` fetches of the base pull the full tree with blobs; context repositories are small, but a large one costs one fetch per step.
- Ref age comes from the tip's commit time (the run's author time), not the push time. A run that lasts more than 24 hours loses its refs; the shard limit is lower.
- If `INGESTION_V2_SHADOW` changes to false while shadow refs exist, the next tip check deletes finished shadow refs early.
