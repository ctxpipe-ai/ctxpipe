# Brief — ctx| identity, pass 3 (brand)

Pass 2 was technically green and **generic**. This pass starts from the **shipped pixel `ctx|`** and treats personality as a requirement.

- **Name / pitch:** ctxpipe — self-learning context layer for autonomous AI agent fleets (and their humans). Engineers. Terminal-native, not a SaaS wordmark.
- **Job:** a **brand**, not a typeset string. Someone should remember it after one look.
- **Surfaces:** dark UI first; light; 20px sidenav; 16px favicon; merch / one-color.
- **Color:** teal `#40E0D0` on dark; darker teal on light. Ink `#F4F4F5` / `#09090B`. Teal is the accent, not a wash.
- **Protect from the current mark:** the reading `ctx|`; the **pixel grit**; the **oversized teal pipe / cursor**; sharp corners (`rounded-none`).
- **Do not protect:** white-only (fails light); the pass-1 two-inlet L diagram; the pass-2 “just Geist `ctx|`” safety.
- **Allowed to divert:** new marks, lockups, badges, offsets, heavier pipes, fleet-scale geometry — as long as it still fits the pitch and does not read as a broken equals-sign.

## Each loop

Four **new** directions from the current winner (loop 1 from the shipped logo). Pick one winner. Integrity still kills homemade unrelated bars, white-on-white, and accidental `+` / hamburger. A coherent pixel system is brand lettering, not a fail.

## Architectures in play

Wordmark (pixel or display) · letterform-as-symbol (the pipe) · lockup (mark + `ctx|`) · stamp / plaque. One idea per candidate.
