# CTX-718 fix round 1

Issue: [CTX-718](https://linear.app/ctxpipe/issue/CTX-718).

## Changes

1. General uses one MMR selection and a soft answer-kind score boost. A strong runbook query can rank first.
2. The fallback requires fewer than `limit` results or no answer kind. Both searches and walks share a deadline. Embedding requests accept cancellation, including Bedrock. SQL statements have a remaining-time timeout.
3. The merge keeps intent-walk answers, then fallback answers, then other results. A test covers an owner on a link and another owner on a free-form claim, with no `OWNS` edge.
4. ADR-051, its index, and the tool descriptions state these rules.
