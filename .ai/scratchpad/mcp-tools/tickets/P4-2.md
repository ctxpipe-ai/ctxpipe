# P4-2 MCPJam eval suite and CI (CTX-574)

What: `apps/backend/evals/mcp/{cases,check,gate,run}.ts`, `baseline.json`, `.github/workflows/mcp-evals.yaml`.
Why: ADR-051 section 10 gates the release on MCPJam evals. The suite targets the seven-tool set of the P3-7 cutover and also records a `ctx_advisor` baseline before it.
Tests: `src/mcp/eval-suite.test.ts` (30 unit tests, no model): case integrity against fixtures and registered schemas, each check rule, transcript parsing, mode detection, gate thresholds.
Risks: `run.ts` and the workflow cannot run without a seeded target, model keys, and `@mcpjam/sdk`. Baselines are empty until the first live runs. `get_related` arguments are not schema-checked until P3-6 lands.
