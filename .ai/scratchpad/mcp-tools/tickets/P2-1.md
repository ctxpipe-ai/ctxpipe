# P2-1 Unit title, source and updated_at

## What

- Migration `20261013061102_knowledge_unit_metadata_and_chunks` (shared with P2-2): nullable `title` and `source` on `workspace_knowledge_units`. The `updated_at` column was there; it now holds the last commit time of the path, not the row write time. The embedding write no longer changes it.
- `connectorMirrorRoot(path)` in `domain/codeIngestion/connectorMirrorPaths.ts`. `isConnectorMirrorPath` calls it, so there is one source of truth.
- `HydrateUnit.title`, `source`, and `updatedAt` are required. `hydrateKnowledgeTree` sets `title` (front-matter `title`, else the first ATX heading outside a code fence), `source` (mirror root or `authored`), and `updatedAt`.
- `listMarkdownFilesAtGitSha` gives `lastCommitTimestamp` from the same history walk that gives the introducing commit (`--diff-filter=AMT`, newest first). The history buffer is now 128 MB.

## Why

ADR-051 section 8: search filters by source and time, and results show titles.

## Tests

- `knowledge-chunks.integration.test.ts` (real Postgres, real Git, hydrate workflow): all six mirror kinds and an authored unit get the right title, source and commit time. The reuse test also checks that an edited path gets the second commit time and an unchanged path keeps the first.
- `clone-tree.test.ts`: introducing and last commit time for an edited and an unchanged path.
- `hydrate.test.ts`: title rules (front matter, heading, fenced `#`, none), source, updatedAt.
- `connectorMirrorPaths.test.ts`: the root of each mirror kind; null for authored paths.
- Migration: applied on a fresh database, and on a database with a unit row from before (the new columns are null).

## Risks

- Units hydrated before this change get `title`, `source`, and the commit time on the next hydrate run of their revision (P2-2 backfill), which also runs the graph and index phases again once. Until a run happens, they stay null.
- The history walk now reads modifications as well as additions. A very long mirror history can approach the 128 MB buffer.
