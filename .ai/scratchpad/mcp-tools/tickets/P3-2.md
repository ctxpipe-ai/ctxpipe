# P3-2: search_knowledge

Issue: [CTX-604](https://linear.app/ctxpipe/issue/CTX-604).

## Scope

Add `searchKnowledgeTool` in `mcp/tools/search-knowledge.ts`. Use the existing
`searchKnowledge` domain function and MCP framework. Keep registration for the
seven-tool cutover, as ADR-051 requires.

The tool returns one best chunk for each unit, with a Workspace slug, file ref,
line range, and served revision. Search all Workspaces of the org by default.
Require an explicit selection when the org has more than eight Workspaces.
Forward the kind, path, source, update time, and validity filters to SQL.

Page the top 50 ranked units that the domain function returns. Bind each cursor
to the org, selection, filters, and projection SHAs. A narrower query can reach
units outside this bounded result set. Apply the 4,000-token estimate and the
24,000-character wire cap to the complete result.

## Proof

Use the MCP SDK Client, Hono routes, real Postgres as `ctxpipe_app`, and msw at
the embedding endpoint. Do not replace an owned collaborator.

Verification is in progress.
