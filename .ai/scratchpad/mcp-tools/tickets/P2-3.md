# P2-3 Indexed hybrid knowledge search: notes from the P2-2 review

## Must do

- Set `hnsw.iterative_scan` (for example `SET LOCAL hnsw.iterative_scan = relaxed_order`) in the search transaction. Filtered HNSW scans otherwise return too few rows. This needs pgvector 0.8.0 or later.
  - Local Compose Postgres: pgvector 0.8.2.
  - Neon production pgvector version: still not checked (the Neon MCP did not connect). The search now reads the version and uses `hnsw.iterative_scan` only from 0.8.0, so a lower version no longer fails; it raises `hnsw.ef_search` instead.
- The HNSW branch keeps a bare `ORDER BY distance` in its inner query, because a longer sort key stops the planner from using the index. Ties are broken in the rank window.
