Loop 2 — Routed Context variations

A Hard Dock · B Pipe First · C Typographic Route · D Asymmetric Route. Same grammar: inputs → teal pipe → output + lowercase ctx.

A. Hard Dock

Inlets physically join the pipe. Longer teal stdout. Three-in / one-out is literal.

B. Pipe First

Heavier, taller teal pipe as the object. Shorter staggered inlets. Pipe is not a divider.

C. Typographic Route

8px stroke shared by mark and letters. Clearly lowercase c, narrow t, open x. No second pipe.

D. Asymmetric Route

Long middle inlet, short flanks, stdout dropped off-center. Less hamburger, more direction.
