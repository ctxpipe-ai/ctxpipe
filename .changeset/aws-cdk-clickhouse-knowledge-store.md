`CtxPipe` deploys ClickHouse 26.10 for the new knowledge store. ClickHouse runs on one Graviton EC2 host in a private subnet. The data is on an encrypted EBS volume, and a stack delete keeps a snapshot of it. The old parts go to a private S3 bucket behind a cache on the volume. Only the backend, the worker and the migrate task reach it, on port 8123. The stack generates the admin, `ctxpipe_reader` and `ctxpipe_writer` passwords. Migrate gets the admin `CLICKHOUSE_URL` and makes the two users, the backend gets the reader URL, and the worker gets the writer URL. The size profiles set the instance and the volume (`small` t4g.large and 50 GiB, `medium` r7g.large and 100 GiB, `large` r7g.xlarge and 200 GiB). The VPC gets an S3 gateway endpoint, and `ctxPipe.knowledgeStoreAlarms` holds an alarm for when no ClickHouse host is in service. The first deploy of this version adds these resources and replaces nothing that holds data. The new knowledge store stays off for every organization.
