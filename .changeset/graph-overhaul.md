Graph ontology v2 (ADR-033). Predicates are grouped into relation families (`PART_OF`, `DECLARED_IN`, `TARGETS`, `REFERENCES`, `OWNS`, `SUPERSEDES`, `INFLUENCES`, change edges dated at merge); the overloaded `ABOUT` and the never-extracted `Concept` / `Capability` / `Topic` kinds are retired. Connector Markdown is parsed by deterministic extractors instead of the instruction LLM: Linear issues and teams (`Issue`, `Team OWNS Issue`, `Issue REFERENCES PullRequest`), Slack captures (`Thread REFERENCES PullRequest | Issue`), and the GitHub pull-request mirror (`PullRequest TARGETS Repository`, change edges, `PullRequest REFERENCES Issue`). Source repositories gain `Decision` nodes from ADR files and `Team OWNS Service | App | Library` from CODEOWNERS. One reference resolver joins URLs, identifiers and paths into shared keys. Evidence ids now follow `extractor:repositoryId:…:targetHash` so dedup, retraction and purge work for connector claims. Connector-only partial ingests skip the code extractors. New `GET /knowledge-graph/quality` (join density, orphans, evidence per claim) and admin `POST /knowledge-graph/maintenance/retract-connector-instructions` to remove legacy connector-derived instruction units. Re-ingest connected repositories after deploying.
