Knowledge search: a Markdown section that holds only its heading line now joins the next section, so that no search hit shows only a heading. When hydrate or the knowledge plane projects a unit again, it embeds again only the chunk after each heading-only section of that unit. MCP read-tool spans now record the argument names, the query length, the result count, and the top score, but no query text.
