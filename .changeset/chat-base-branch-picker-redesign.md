Chat: the base branch of a new conversation is a quiet branch control in the composer footer, with a menu that has a search field. The control shows the default branch at once; only the menu waits for the branch list. After the first message, the conversation header names the base branch and the session branch as plain text. The suggested prompts are a centered row of short pills under the composer; a pill puts its full prompt in the composer. The Workspace API adds `defaultBranch` (CTX-1468).
