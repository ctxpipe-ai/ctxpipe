Connectors bring content from the tools your team uses into a
[Workspace](/docs/workspaces). ctx| is git-first: every connector writes
Markdown into the Workspace's repository, so you can see, review, and keep
exactly what ctx| and your agents rely on.

You choose what each connector may read and which Workspace it writes to.

## GitHub is the foundation

Connect GitHub first. The ctx| GitHub App lets ctx|:

- read and write workspace repositories;
- index linked code repositories for search and extraction;
- open pull requests for connector configuration and Workspace chat changes.

## Two source behaviors

- **Scoped mirrors**: Linear, Notion, Confluence, PagerDuty, and GitHub pull
  requests. You approve a scope through a configuration pull request; ctx|
  then keeps the selected content current in the Workspace.
- **Intent capture**: Slack writes one existing thread only when someone
  mentions the bot inside it. There is no channel mirror or history backfill.

Because everything lands in git, you get:

- a visible history of what changed and when;
- a review surface for scope changes;
- one indexing path for code, docs, and mirrored content;
- control over what agents can rely on.

## Agents use ctx| through MCP

MCP is how agents read a Workspace, not another source. See
[ctx| MCP](/docs/mcp/mcp-docs).
