ctxpipe is open source under the **MIT License**. The core includes each job
that writes to your Workspace, so you can read exactly what changes your
knowledge. You can use, copy, change, and distribute the software. The
`LICENSE` file in the repository is the binding text. This page is not legal
advice.

## Repository

The source is at
[github.com/ctxpipe-ai/ctxpipe](https://github.com/ctxpipe-ai/ctxpipe), a pnpm
and Turborepo monorepo:

| Path | What it is |
| --- | --- |
| `apps/backend` | The API, the MCP server, auth, the database schema, and the background jobs (Hono on Bun) |
| `apps/ui` | The web app (TanStack Start and React) |
| `apps/codesearch` | Code search, code navigation, and repository checkout (Zoekt and SCIP) |
| `apps/forge-ctxpipe-agent` | The Atlassian Forge app for Confluence |
| `apps/docs` | This documentation site |
| `packages/cli` | The `ctxpipe` CLI for MCP and local memory setup |
| `packages/aws-cdk` | The AWS CDK construct for self-hosting |
| `plugins/ctxpipe` | The Claude plugin |
| `examples/` | Runnable examples, such as an AWS CDK deployment |

## Hosted and self-hosted

Hosted ctxpipe runs the same open-source core. Self-host it for full control of
your data and infrastructure, or use hosted ctxpipe so that we operate it for
you. See [Self-hosting](/docs/self-hosting).

## Contribute

Issues and pull requests are welcome on GitHub. Read `CONTRIBUTING.md` for
local development. Before a large change, read the architecture decisions in
`.ai/memory/decisions/`, so that your proposal agrees with them.

## Report a security problem

Do not report a security problem in a public issue, and do not post secrets.
Use a private GitHub security advisory on the repository, or the contact
channels on [ctxpipe.ai](https://ctxpipe.ai).
