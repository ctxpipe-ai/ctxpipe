## Product

### What is ctxpipe?

Context management for teams that ship with AI coding agents. ctxpipe keeps
your code, decisions, tickets, docs, and incidents as Markdown in a git
repository that you own, keeps it current with background jobs, and serves it
to each coding agent through one MCP endpoint. See
[Getting started](/docs/getting-started).

### How is ctxpipe different from giving an agent more MCP servers?

More servers give an agent more to read, not a way to tell what is true.
ctxpipe gives each agent the same reviewed context: files in git with sources,
history, and links to the code. Your agent cites the files that it used. See
[Use ctxpipe from your agent](/docs/mcp/use-from-your-agent).

### Does ctxpipe train on my code?

No. On hosted ctxpipe, each model call goes only to zero data retention
endpoints. See [Data and privacy](/docs/resources/data-processing).

## Connections

### Which sources can I connect?

GitHub, Linear, Notion, Confluence, PagerDuty, Buildkite, and Slack, plus public
repositories on any git host. Linear, Notion, Confluence, PagerDuty, and Buildkite mirror
the scope that you approve. Slack captures one thread when someone mentions the
bot. See [Connections](/docs/connections).

### Is ctxpipe only for GitHub?

ctxpipe writes Workspace repositories through the GitHub App, and reads private
code through it. Other git hosts work as read-only sources: ctxpipe reads a
public repository on any host with no credential. A private repository on
another host does not work yet. See
[Plain git repositories](/docs/workspaces/linked-repositories#plain-git-repositories).

### What is the difference between a connection and a source?

A connection is the authorization for one tool. A source is a file in a
Workspace that names the connection and the scope. One connection can feed many
Workspaces.

### Does ctxpipe scan my laptop?

No. ctxpipe reads only the repositories and tools that you connect. It installs
nothing on developer machines. [Local memory](/docs/mcp/local-memory) is
Markdown in your repository, and it leaves your machine only when you push it.

### Does ctxpipe write to my code repositories?

No. ctxpipe only reads linked code repositories. It commits only to Workspace
repositories, and it opens pull requests for source changes, upgrades, and
Workspace chat.

## MCP

### How does a tool call choose the organization?

The `/mcp` URL is the same for each organization. Each tool call names one
organization in the `org` argument. ctxpipe allows the call only when the
organization is in the set that you selected for the client, and you are still
a member. The tools have no organization id that an agent can change. See
[Use ctxpipe from your agent](/docs/mcp/use-from-your-agent).

### Which transport does the MCP use?

Streamable HTTP. A client that supports only the old SSE transport can fail.

### Can an agent change data through the MCP?

No. All seven tools are read-only.

## Account and organization

### How do invitations work?

An owner or admin sends an email invitation from **Organization settings →
Members**. See [Invite by email](/docs/managing-organization#invite-by-email).

### Can one person belong to many organizations?

Yes. Switch with the organization switcher. The URL always names the
organization. An MCP client can read each organization that you select for it.

### Can I verify my company domain?

Not yet. Access to an organization comes from invitations and roles. If you need
domain verification, [get in touch](/docs/getting-started/get-in-touch).

## Self-hosting

### What is the fastest way to evaluate a self-hosted deployment?

Docker Compose: `pnpm start` runs the `deploy` profile. See
[Docker](/docs/self-hosting/deployment/docker).

### Which databases does ctxpipe need?

PostgreSQL with pgvector, and a graph database. FalkorDB is the default. Neo4j,
Memgraph, and Amazon Neptune also work. See
[Graph databases](/docs/self-hosting/graph-databases).

### Which model providers work?

Each OpenAI-compatible provider, for example OpenRouter, Azure OpenAI, or
Ollama. Amazon Bedrock also works. See [Models](/docs/self-hosting/models).
