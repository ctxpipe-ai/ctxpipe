ctx| keeps your team's knowledge in a git repository and keeps it current. You
create a **Workspace** for a body of knowledge: its workspace repository holds
Markdown knowledge and content mirrored from your tools, and its linked
repositories hold the code it searches. People ask questions in Workspace
chat; AI coding agents ask through MCP.

## What ctx| gives you

- **Knowledge in git**: Markdown files you can review, edit, and keep, even
  without ctx|.
- **Connectors** that mirror selected Linear, Notion, Confluence, PagerDuty,
  and GitHub pull request content, and capture Slack threads on request, as
  files in the Workspace.
- **Code search and extraction** across the repositories you link.
- **A knowledge graph** built from links and claims in the files.
- **Workspace chat**: an agent that answers questions and proposes changes as
  pull requests.
- **One MCP endpoint** for Cursor, Claude Code, Codex, OpenCode, and other
  agent clients.
