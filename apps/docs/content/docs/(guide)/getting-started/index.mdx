description: ctxpipe keeps your engineering knowledge current in git and serves it to every coding agent over MCP.

Your coding agents can reach every repository, ticket, doc, and Slack thread.
They cannot tell which parts are true. ctxpipe gives them one current source of
context that you can read, review, and correct.

1. **Connect.** [Link your code repositories](/docs/workspaces/linked-repositories),
   and [select what to bring in](/docs/connections) from Linear, Notion,
   Confluence, PagerDuty, and Slack. ctxpipe writes it as Markdown into one git
   repository for each [Workspace](/docs/workspaces).
2. **Keep current.** Background jobs mirror changes from your tools, and read a
   linked repository again after each push. Each job makes one small commit
   that you can review or revert. Then ctxpipe
   [indexes the new commit](/docs/workspaces/indexing) for search and the graph.
3. **Serve.** Claude Code, Cursor, Codex, OpenCode, and VS Code read the same
   Workspace [through one MCP endpoint](/docs/mcp/mcp-docs). ctxpipe returns
   sources, not answers. Your agent reasons with its own model.

## Who ctxpipe is for

ctxpipe is for engineering teams that ship with AI coding agents across many
repositories, and for the platform engineers who set up those agents. It helps
when:

- agents repeat mistakes that a decision record or a runbook already explains;
- the context for one change is in several repositories and tools;
- you must see what an agent read, and correct it in one place.

## Key terms

| Term | Meaning |
| --- | --- |
| **Organization** | Your team in ctxpipe. It holds members, connections, and Workspaces. |
| **Workspace** | One body of knowledge, for example one product or one team. |
| **Workspace repository** | The git repository of Markdown that holds the knowledge of a Workspace. You own it. |
| **Linked repository** | A code repository that a Workspace indexes for search. |
| **Connection** | The authorization for one tool, such as Linear or Notion. |
| **Source** | A file in the Workspace repository that says what to read through a connection. |
