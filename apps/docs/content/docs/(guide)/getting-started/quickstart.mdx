This guide sets up hosted ctxpipe with one Workspace, and connects it to your
coding agent.

<Callout type="info" title="Hosted ctxpipe is in early access">
  We help you set up your first Workspace.
  [Request early access](https://ctxpipe.ai/early-access) or
  [book a demo](https://cal.com/ctxpipe/30min). To run ctxpipe on your own
  infrastructure, start with the
  [self-hosting quickstart](/docs/self-hosting/quickstart).
</Callout>

## Before you start

You need:

- permission to install the ctxpipe GitHub App on your GitHub account or
  organization, or a GitHub owner who can approve it;
- a GitHub repository for the knowledge of the Workspace. An empty repository
  is good. You can create one during setup;
- the code repositories to link;
- an MCP client: Claude Code, Cursor, Codex, OpenCode, or VS Code with
  Copilot.

## 1. Sign up and create your organization

Sign up at [app.ctxpipe.ai](https://app.ctxpipe.ai), then create an
organization. With a work email, ctxpipe suggests a name from your email
domain. If a teammate invited you, you join their organization.

**Home** then shows the **Get started** guide. It lists the next steps and marks
each step done when ctxpipe sees the result.

## 2. Connect GitHub

In the guide, choose **Connect GitHub**. Install the ctxpipe GitHub App on the
account or organization that owns your repositories. Give it access to the
repository for the knowledge, and to the code repositories that you want to
link. You can add repositories later in GitHub.

A GitHub account can belong to one ctxpipe user only. See
[GitHub connector](/docs/connections/source-connectors/github).

## 3. Create a Workspace

Choose **Create Workspace**, then choose the Workspace repository:

- **Select GitHub**: use a repository that you have on GitHub.
- **Create on GitHub**: create a new repository on GitHub, then select it.
- **Paste URL**: use any other git URL. ctxpipe cannot write to it, so the
  Workspace is read-only.

ctxpipe adds `AGENTS.md` and a knowledge skill if they are missing, and starts
to read the repository. See [Create a Workspace](/docs/workspaces/create-workspace).

## 4. Link code repositories

The next step shows the **Sources** of the new Workspace. Choose **Add
repositories**, select the code repositories, and choose **Open a pull
request**. Merge the pull request on GitHub. Each repository then goes from
**Pending** to **Indexing** to **Indexed**.

To link more repositories later, open the **Settings** tab of the Workspace.
See [Linked repositories](/docs/workspaces/linked-repositories).

## 5. Ask a question

Type a question in the Workspace, and ask for the files behind the answer:

```text
What should a new engineer read first, and which files support that answer?
```

You can ask while ctxpipe indexes. The answers improve when indexing is done.
See [Workspace chat](/docs/workspaces/chat).

## 6. Connect your coding agent

The **Get started** guide has a **Use ctxpipe from your agents** block with the
setup command. Copy it, and run it in a repository:

```bash
npx ctxpipe init
```

The CLI signs you in, asks which organization and agent clients to configure,
and writes the MCP configuration. The first time your agent connects, it asks
you to authorize ctxpipe in the browser. See
[Connect your agent](/docs/mcp/mcp-docs).

Then give the agent a real task:

```text
Use ctxpipe before you plan this change. Search the knowledge for the
standards and decisions that apply, search the code for the related areas,
and say what still needs a check in the code.
```

## 7. Connect your tools and invite your team

- Open **Connectors** to add Linear, Notion, Confluence, PagerDuty, Buildkite, or Slack.
  See [Connections](/docs/connections).
- Open **Organization settings → Members** to invite your team. See
  [Organizations and members](/docs/managing-organization).

## Setup is complete when

- the linked repositories show **Indexed** in the **Settings** of the Workspace;
- Workspace chat answers a question and names useful files;
- your agent can call `list_workspaces` and `search_knowledge`.
