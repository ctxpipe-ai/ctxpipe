## Product & website

- **Product information & overview:** [ctxpipe.ai](https://ctxpipe.ai)
- **Hosted product:** SaaS option for teams wishing to get started ASAP. For commercial or
  deployment questions, contact the team through the site’s channels.

## Documentation & open source

- **Public docs (hosted):** [docs.ctxpipe.ai](https://docs.ctxpipe.ai) - you are here!
- **Source code:** [github.com/ctxpipe-ai/ctxpipe](https://github.com/ctxpipe-ai/ctxpipe)
- **Issues & contributions:** GitHub issues and PRs on the repo above; see
  [Open source](/docs/resources/open-source) for license (ELv2) and philosophy.

## Contributors

If you are extending the open-source stack, start with the repository README and
the [open-source overview](/docs/resources/open-source). Contributor-specific
runbooks and architecture records live with the source so they can evolve with
the implementation.
