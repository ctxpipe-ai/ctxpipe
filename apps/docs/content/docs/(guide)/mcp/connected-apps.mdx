---
title: Connected apps
description: See the apps that you connected to ctx| with OAuth, change the organizations each app can read, and revoke an app.
---

When an MCP client signs in to ctx| with OAuth, you allow it on a consent page.
**Connected apps** lists each app that you allowed. Use it to change what the app
can reach, without a reconnect.

## Open the page

Open your account settings and choose **Connected apps**. On a hosted
deployment, the page is at `https://app.ctxpipe.ai/.auth/account/connected-apps`.

## What the page shows

For each app, the page shows the client name, the scopes that you granted, and
the organizations that the app can read.

## Choose the organizations

On the consent page, ctx| lists your organizations with check boxes. The
organization of your current session is ticked. You must tick at least one.

An app can read only the organizations in its set. A new membership never joins
an existing connection by itself. Tick it on **Connected apps** to add it.

To change the set:

1. Choose **Edit organizations** for the app.
2. Tick or clear organizations.
3. Save.

The change applies on the next tool call. The app does not need to reconnect.

## Revoke an app

Choose **Revoke** for the app. The app loses access at once, and it must ask you
to authorize again.

## When a tool says `org_not_found`

The tool call named an organization that is not in the connection. You may also
have left that organization. Add the organization on **Connected apps**, then
call the tool again.

An older connection that holds one organization appears in the list as well. You
can only revoke it.

## API keys

API keys are not apps. An organization key reads one organization. A personal key
reads every organization that you are a member of. See
[API-key auth](/docs/mcp/mcp-docs#api-key-auth).
